# Floor plans

Images in this folder appear in the "Find My Office" card of the Faculty Portal.

Name each file `<BUILDING>-<FLOOR>.<ext>`, for example `PLG-2.png` or `AIC-3.svg`.
The building code must match the one used for offices (AIC, PLG, LBV, FPA...).
Accepted formats: .svg, .png, .jpg, .jpeg, .webp.
